# 🌊 Fluxshell

> *A simple AGS bar born from the rabbit hole that is Linux ricing.*

---

## What is this?

Fluxshell is a custom status bar for Hyprland, built with [AGS (Aylur's Gtk Shell)](https://github.com/Aylur/ags) using TypeScript and GTK4.

It started because I got introduced to one of the most entertaining things in Linux — **ricing** — and I hadn't started yet. So here we are.

---

## Features

- 🕐 **Clock** — Shows the current time and date. Clicking it opens a calendar popup.
- 🖥️ **Workspaces** — Hyprland workspace switcher with Japanese numerals (一 二 三...) for the active workspace, and dots for the rest.
- 🔋 **Battery** — Shows current battery percentage.
- 🔵 **Bluetooth** — Shows Bluetooth connection status and lets you toggle it.
- 📶 **Network** — Shows Wi-Fi/Ethernet status with a toggle.
- 🔊 **Audio** — Shows current volume level with a mute toggle.
- 🔔 **Notifications** — Toast-style popups for incoming notifications (auto-dismiss after 2.5s).

---

## Dependencies

- [Hyprland](https://hyprland.org/) — Wayland compositor
- [AGS v2](https://github.com/Aylur/ags) — Shell framework (GTK4 + TypeScript)
- [libastal](https://github.com/Aylur/astal) — Astal libraries (Hyprland, Battery, WirePlumber, Network, Bluetooth, Notifd)
- [matugen](https://github.com/InioX/matugen) — Material You color generation

---

## Colors

Fluxshell reads its color palette from `~/.config/ags/colors.css`, which uses CSS `@define-color` variables. Colors are generated by [matugen](https://github.com/InioX/matugen), which builds a Material You palette from your wallpaper and outputs it straight into that file.

---

## Running it

```bash
ags run
```

Make sure your `colors.css` is in place and all Astal libraries are installed before running.
